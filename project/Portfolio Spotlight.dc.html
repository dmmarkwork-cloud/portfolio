How I work

A result is only as good as the gate it passed.

01 — GATED PHASES

Hand calculation before CAD, CAD before mesh, mesh before load. Each phase validates against the one before it — area–Mach against CFD, CFD wall integral against FEA reaction, FEA against thin-wall theory.

02 — CLASSIFIED STRESS

Linearised membrane + bending on a through-thickness path, not a body-scoped probe maximum. Singular re-entrant peaks are identified and excluded, not quietly reported as the answer.

03 — CONVERGENCE OR A BAND

Where refinement converges monotonically I report a converged value (0.62 % between meshes). Where it does not, I report a band — 7.02 to 7.12 — rather than a false single figure.

04 — FAILURES STAY VISIBLE

Two of seventeen gates failed on the nozzle; the tank misses its own FoS target at 1.91. Both are published with their consequence bounded, not re-scoped into a pass.

05 — TRACEABLE VALUES

Every dimension, tolerance and fit in the DFM package is tied to a source and a claim tier in a value register — down to a gasket bolt load taken from ASME BPVC VIII-1 Appendix 2.

06 — MAKEABLE OR IT ISN'T DONE

Analysis carries into a drawing set: GD&T to ASME Y14.5-2018, tolerance stack-ups that close against the frozen FEA geometry, a machining route, inspection plan, BOM and RFQ.
